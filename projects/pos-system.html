DairyBarn Point-of-Sale System

DairyBarn is a point-of-sale system developed for CIS 400: Object-Oriented Design. The project combines a WPF desktop application with a Razor Pages web interface, emphasizing object-oriented design, reusable architecture, and realistic business workflows.

01 / 06

01 · Overview

What is DairyBarn?

DairyBarn was designed as a complete point-of-sale system for a vendor. The goal was to create a flexible system capable of handling common sales operations while maintaining a reusable and organized architecture.

The project was developed as part of CIS 400: Object-Oriented Design at Kansas State University.

02 · My Role

What I worked on.

From the ground up, DairyBarn was designed to be reusable and adaptable. I focused on implementing application functionality while helping structure the system around object-oriented design principles.

  • Implemented application functionality in C#
  • Developed the desktop interface using WPF
  • Worked with Razor Pages for the web interface
  • Applied object-oriented design principles
  • Designed and documented system architecture using UML diagrams

03 · Technology

Built With

C# WPF Razor Pages UML

04 · Development

Designing the system.

A major focus of the project was software design. Rather than building only an interface, the system was structured around object-oriented programming, reusable classes, interfaces, and a defined application architecture.

UML diagrams were used to model the structure and relationships within the system throughout development. This helped translate the planned architecture into the implemented application.

05 · Reflection

Epilogue

DairyBarn was one of my more substantial software engineering projects because it required me to think beyond individual functions and consider how the different parts of a larger application work together.

The project strengthened my understanding of object-oriented design, software architecture, interface development, UML, and collaborative software development.
