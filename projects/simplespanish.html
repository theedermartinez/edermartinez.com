Project · 2024/2025

SimpleSpanish
A Spanish learning app

SimpleSpanish is an Android application I developed independently to make Spanish practice simple, accessible, and free from the heavy advertising and subscription model common in language-learning applications.

The application was originally developed under the name MartianFox Softworks, which appears in the application demo. The project later remained a personal software project rather than becoming a larger software venture.

01 · Overview

Purpose of the app

I became tired of applications that restricted language learning behind a paywall or too many ads. During my free time, I created this demo for Android devices. My goal was to create a visually appealing application that encouraged learning Spanish.

02 · My Role

Designed and developed independently.

SimpleSpanish was a solo project, meaning I handled the design, implementation, application structure, and supporting data myself.

  • Designed and implemented the Android application in Java
  • Built the application interface and user interactions
  • Structured lesson and application data using JSON
  • Worked with Android permissions and device storage
  • Configured the project using Groovy and Android Studio

03 · Technology

Built with.

Java Groovy Android Studio JSON

04 · Development

Learning Android development.

SimpleSpanish was one of my first projects focused specifically on mobile development. Although I already had experience with Java, Android introduced a new set of concepts involving application lifecycles, permissions, storage, and device-specific behavior.


Working through these challenges taught me how software designed for mobile devices differs from traditional desktop applications. Debugging permissions and persistent data was particularly useful in understanding how an application interacts with the underlying device.

05 · Research

Documentation & references.

I used the built-in Android documentation and GeeksforGeeks to understand the functionality provided by Android and how different components of the platform work.

  • Android Developer Documentation
  • GeeksforGeeks Android Tutorial
  • Oracle Developer Java Documentation

06 · Reflection

Epilogue.

SimpleSpanish gave me practical experience taking a software idea from concept to a working mobile application. More importantly, it introduced me to the challenges of developing for a platform with its own permissions, storage model, tooling, and development constraints.


The project also taught me a useful lesson about software projects: not every idea needs to become a company or a long-term product. SimpleSpanish began under the name MartianFox Softworks as I explored the possibility of building a larger software venture with people in my life, but ultimately remained a personal project focused on learning and experimentation.
