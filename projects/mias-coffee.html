Project · 2023

Mia's Coffee
An E-Commerce Website

Mia's Coffee was one of my first web development projects, created during my first semester studying computer science in 2023. I built the site from scratch using HTML, CSS, JavaScript, and JSON to create a functional coffee storefront.

01 / 06

01 · Overview

Building a simple storefront.

Mia's Coffee is a small e-commerce-style website designed around a fictional coffee shop. The site includes product listings, interactive elements, and JSON-based data to simulate a basic storefront.

Visit Mia's Coffee

02 · My Role

Learning the fundamentals.

I built the project independently and intentionally kept the implementation simple. The goal was to understand how HTML, CSS, JavaScript, and JSON work together rather than relying on frameworks or complex abstractions.

  • Designed the website structure with HTML
  • Created the visual styling with CSS
  • Added interactive functionality with JavaScript
  • Used JSON to organize application data

03 · Technology

Built from scratch.

HTML CSS JavaScript JSON

The project was written by hand without AI-generated code. Building it this way gave me an early understanding of how the different parts of a web application interact and helped establish the foundation I later built on with more advanced development tools.

04 · Research

Research & references

I used web development documentation and reference material to learn the fundamentals needed to build the project.

  • Learning Web Design — O'Reilly
  • Mozilla Web Documentation

05 · Reflection

Epilogue

Mia's Coffee was one of the first complete software projects I built. It gave me the confidence to take what I was learning and turn it into something functional.

While the project is simple compared with my later work, it established my interest in software development and gave me a foundation in how websites are structured, styled, and made interactive.
